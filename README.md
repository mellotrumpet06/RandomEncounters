# RandomEncounters
Personal Project for DMs to come up with random encounters in dnd


This program will feature:

- determining the party level

- determining the environment the party is in

- from the party level and the environment, the program will provide either example encounters or will randomize from a list of encounters (encounters.md)

- if the DM wants to randomize again or see different examples, the code will run the last bullet point again

- once DM inputs "Done", the program will end
